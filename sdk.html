KRYPTONOS-SDK(7)

Build applications for KryptonOS

Applications are compiled into one ESP32 firmware image and run as managed FreeRTOS tasks. This is a source-level SDK, not a dynamic plugin loader.

1. Create a project

cd KryptonOS
python3 tools/krypton_app.py ../MyKryptonApp
pio run -d ../MyKryptonApp

The generator links both KryptonOS and KryptKernel. Use --krypton-root and --kryptkernel-root when repositories are not adjacent.

2. Register an app

#include <KryptonApp.h>

KryptonOS::System os;

void appSetup() { pinMode(2, OUTPUT); }
void appLoop() { digitalWrite(2, !digitalRead(2)); }

void setup() {
  Serial.begin(115200);
  os.registerApp(KRYPTON_APP("blink", appSetup, appLoop));
  os.boot();
}

void loop() { os.run(); }

Apps support up to eight unique names. intervalMs, stackSize, and priority configure the task.

3. Flash and launch

pio run -d ../MyKryptonApp -t upload
pio device monitor -b 115200

In the serial console:

apps
apps blink

apps lists registered apps and their state. apps blink starts the stopped app; its setup runs once and its loop runs in its own kernel-managed task.
