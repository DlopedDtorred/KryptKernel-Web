KRYPT(8) System Manager Manual KRYPT(8)

NAME

krypt - monolithic kernel initialization and compilation manual

SYNOPSIS

git submodule add https://github.com/DlopedDtorred/KryptKernel.git lib/KryptKernel

DESCRIPTION

To include the kernel in your ESP32 project sketch, include the master header file <Krypt.h> and instantiate the global kernel controller.

Example: main.cpp
#include <Arduino.h>
#include <Krypt.h>

// Instantiate the Kernel globally
KryptKernel Krypt;

void setup() {
  Serial.begin(115200);

  // Boot up all kernel modules (HAL, FS, Task, Net)
  if (Krypt.boot()) {
    Serial.println("[OK] Krypt Kernel booted successfully");
  }

  // Read telemetry through KryptHAL
  uint32_t freeRam = Krypt.hal.getFreeRAM();
  Serial.printf("Free Memory: %d KB\n", freeRam / 1024);
}

void loop() {
  // FreeRTOS handles background tasks automatically
}
